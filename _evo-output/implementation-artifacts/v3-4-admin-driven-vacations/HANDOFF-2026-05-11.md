## Gotchas descobertas (anotar)

### Fastify autoload pode ignorar arquivos silenciosamente
- Sintoma: arquivo `.js` está em `dist/`, mas a rota retorna 404 e nenhum log de boot do plugin.
- Workaround: mover a rota pro `index.ts` do mesmo dir.
- Caso real: `routes/api/v1/admin/vacations/import-operational.ts` foi ignorado, movido pra `index.ts` no commit `94578c5`.

### Tirvu Gestão Operacional — encoding e datas
- Encoding ANSI/Win1252 quebrado: "F�RIAS" (U+FFFD). Normalizar pra "FERIAS" antes de comparar.
- **Algumas linhas têm Fim Vigência < Início Vigência** (anti-natural). O importer faz auto-swap.
- Datas vêm como Excel serial number OU string `dd/MM/yyyy` — parser trata ambos.

### SSE endpoints (raw response) precisam CORS manual
- `@fastify/cors` aplica em respostas normais. `reply.raw.write()` bypassa o plugin.
- Setar `Access-Control-Allow-Origin: <request.headers.origin>` + `Access-Control-Allow-Credentials: true` + `Vary: Origin` manualmente.
- Fix em `/coverages/events` e `/predict/ask/stream`.

### Service Worker e cross-origin
- O SW antigo interceptava fetches cross-origin (frontend→backend domínios diferentes) e tentava cachear undefined → crash "Failed to convert value to 'Response'".
- Fix: SW agora só intercepta same-origin GETs. Cache name `gestao-ferias-v3`.

### Coverage anti-overlap DB constraint
- `btree_gist` EXTENSION + EXCLUDE constraint usando `daterange(start, end, '[]')`.
- Migração `20260510130000_v3_4_coverage_no_overlap`.
- Importer faz auto-swap quando Tirvu manda dates invertidas (caso contrário o constraint rejeita com SQLSTATE 23P01).
